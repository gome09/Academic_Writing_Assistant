# 绪论

## 研究背景与意义
随着城市生活垃圾产量逐年上升，垃圾分类已成为环境治理的重要环节。传统人工分类效率低、成本高，难以满足大规模场景需求。深度学习在图像识别领域取得突破，为自动化垃圾分类提供了新思路。本课题面向校园场景，研究一套可部署于边缘设备的垃圾图像分类系统，具有现实意义。

## 国内外研究现状
国外方面，ImageNet 竞赛推动了卷积神经网络的发展，ResNet、EfficientNet 等模型在图像分类上表现优异。国内研究者将其应用于垃圾分类，但多数模型体积大、推理慢，难以在移动端实时运行。轻量化模型与模型压缩是当前研究热点。

## 研究内容与技术路线
本文主要工作包括：构建校园垃圾图像数据集、设计轻量化分类网络、在边缘设备上完成部署与优化，并通过实验验证系统的准确率与实时性。

# 相关理论与技术

## 卷积神经网络
卷积神经网络通过卷积层、池化层与全连接层的堆叠，自动提取图像的层次化特征，是当前图像分类的主流方法。

## 模型轻量化方法
包括深度可分离卷积、通道剪枝、知识蒸馏与量化等，可在保持精度的同时显著降低参数量与计算量。

# 系统设计与实现

## 总体架构
系统分为数据采集、模型推理与结果展示三个模块。前端采集图像，边缘端运行轻量化模型完成分类，结果通过界面反馈给用户。

## 数据集构建
采集校园常见垃圾图像共计 12000 张，划分为可回收物、厨余垃圾、有害垃圾、其他垃圾四类，按 8:1:1 划分训练、验证与测试集。

## 模型训练与优化
以 MobileNetV3 为骨干网络，采用迁移学习进行训练，并结合知识蒸馏进一步压缩模型，最终模型体积约 4MB。

# 实验与结果分析

## 实验环境与评价指标
实验在配备 NVIDIA GPU 的工作站上训练，在树莓派 4B 上部署测试。评价指标包括准确率、推理延迟与模型体积。

## 结果分析
测试集分类准确率达到 94.2%，在树莓派上单张推理延迟约 85ms，满足实时性要求。与基线 ResNet50 相比，模型体积缩小约 90%，准确率仅下降 1.5 个百分点。

# 总结与展望

## 工作总结
本文设计并实现了一套面向校园的轻量化垃圾图像分类系统，验证了轻量化模型在边缘设备上的可行性。

## 研究展望
未来将扩充数据集类别、引入自监督预训练，并探索多模态融合以进一步提升分类准确率与鲁棒性。
